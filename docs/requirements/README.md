# Camera HAT requirements

Requirements for this project.

| ID | Requirement | Priority | Status |
|---|---|---|---|
| CAM-001 | This HAT is a complete project: hardware, case, firmware, software, DAP OS package and its own tooling. | must | Confirmed |
| CAM-002 | Its DAP OS software shall be a custom implementation built on popular open-source software for its domain, optimized for this HAT and the board. | must | Confirmed |
| CAM-003 | It shall mount through the HAT Case Standard. | must | Confirmed |
| CAM-004 | It may include on-board AI features. | should | Draft |
| CAM-005 | The HAT shall turn the device into a GoPro-style action camera. | must | Confirmed |
